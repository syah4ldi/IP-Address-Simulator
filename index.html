DATA ARCHIVE: IP ADDRESS

IP Address (Internet Protocol Address) adalah deretan angka unik yang diberikan kepada setiap perangkat yang terhubung ke jaringan komputer yang menggunakan Protokol Internet untuk komunikasi. Fungsinya seperti alamat rumah, memastikan data dikirim dan diterima oleh perangkat yang tepat.
IP versi 4 (IPv4) dibagi menjadi beberapa kelas berdasarkan oktet pertamanya:

- Kelas A: 1 - 126 (Untuk jaringan sangat besar, misal: ISP)
- Kelas B: 128 - 191 (Untuk jaringan skala menengah)
- Kelas C: 192 - 223 (Paling umum, untuk jaringan lokal/kecil)
- Kelas D: 224 - 239 (Multicasting)
- Kelas E: 240 - 255 (Eksperimental/Riset)
IPv4: Menggunakan format 32-bit (contoh: 192.168.1.1). Memiliki batas sekitar 4.3 miliar alamat, yang saat ini sudah hampir habis.

IPv6: Generasi baru menggunakan format 128-bit (contoh: 2001:0db8:85a3:0000:0000:8a2e:0370:7334). Menyediakan jumlah alamat yang hampir tak terbatas untuk mengatasi kekurangan IPv4.
Subnetting adalah teknik memecah jaringan besar menjadi jaringan-jaringan kecil (subnet). Ini membantu meningkatkan efisiensi dan keamanan jaringan. Subnet mask (seperti 255.255.255.0 atau /24) digunakan untuk memisahkan bagian Network ID (alamat jalan) dan Host ID (nomor rumah) dari sebuah IP Address.
